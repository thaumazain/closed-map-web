本プライバシーポリシーは、PINLOG（以下「本アプリ」）における個人情報の取り扱いについて定めます。

1. 収集する情報

ユーザーが提供する情報

  • メールアドレス：アカウント作成時に収集します
  • パスワード：平文では保存しません。復元できない形式（bcrypt によるハッシュ）に変換して保存します
  • 表示名：アカウント作成時にユーザーが設定します
  • プロフィール写真：任意でアップロードする場合に収集します
  • ログの写真：ログ投稿時にユーザーがアップロードする写真（1件につき最大4枚）
  • ログの説明文・カテゴリ・場所の名称：ログ投稿時にユーザーが入力・選択する情報
  • コメント：他のユーザーのログに書き込むテキスト
  • 通報の内容：不適切なコンテンツを通報する際に選択した理由と、任意で入力する補足説明

端末から自動的に収集する情報

  • 位置情報：ログを投稿する際に、ユーザーの許可を得た上で現在地を取得します。位置情報はログの座標として保存されます
  • クラッシュ情報・エラー情報：アプリが予期せず終了した場合やエラーが発生した場合に、原因調査と品質改善のため、エラーの内容・発生箇所・端末の OS バージョン・アプリのバージョンを収集します。この情報は Sentry（Functional Software, Inc.）のサービスを通じて処理されます。メールアドレス・IP アドレス・表示名は送信されません。

2. 情報の利用目的

  • アカウントの作成・認証・管理（メールアドレスの確認、パスワードの再設定を含む）
  • ログの投稿・マップ表示などのサービス機能の提供
  • フォロー関係に基づくコンテンツの表示
  • 通報への対応・不正利用の防止
  • サービスの改善

3. 情報の公開範囲

本アプリのログ・コメントは一般に公開されません。

  • ログとコメントは、相互にフォローが成立している相手にのみ表示されます
  • 写真へのアクセスは有効期限付きの署名付き URL を通じてのみ提供され、公開 URL では配信されません
  • 検索エンジンに掲載されることはありません

コメントは、そのログが見えるすべての相手に表示されます。投稿者と自分だけのやり取りではありません。

4. 情報の保管

  • サーバー：Amazon Web Services（AWS）EC2（東京・ap-northeast-1 リージョン）上のデータベース
  • 写真ファイル：Amazon S3（東京・ap-northeast-1 リージョン）に暗号化して保存
  • バックアップ：データベースの内容を1日1回 Amazon S3（東京・ap-northeast-1 リージョン）へ保存します。バックアップは7日間保持したのち削除されます

5. 第三者への情報提供

以下の場合を除き、ユーザーの個人情報を第三者に提供・販売することはありません。広告目的での提供・販売は一切行いません。

  • Amazon Web Services, Inc.：サーバー・ストレージの提供のため、本アプリが扱う情報全般を預けています
  • Resend, Inc.：メールアドレスの確認・パスワード再設定・お知らせの送信のため、メールアドレスを渡しています
  • OpenStreetMap の Overpass API 提供者：近くの店舗・施設の名称を検索するため、ログを投稿しようとしている地点の座標のみを送信します
  • Functional Software, Inc.（Sentry）：不具合の検知と修正のため、クラッシュ情報とエラー情報を送信します。メールアドレス・IP アドレス・表示名は送信していません
  • 法令に基づく開示：法律・規制・司法手続きにより開示が必要な場合

Overpass API への座標送信について

  • 送信されるのは座標だけです。メールアドレス・表示名・端末の情報・ユーザーの IP アドレスは送信されません（本アプリのサーバーが代理で問い合わせます）
  • 送信先は overpass-api.de（ドイツ）と overpass.kumi.systems（オーストリア）です
  • この機能を使わなければ座標が送信されることはありません。場所の名称は手入力でも登録でき、入力しなくてもログは投稿できます

6. ユーザーの権利

  • アクセス権：保存されている自分の情報の確認を要求できます
  • 削除権：アプリ内の設定画面からアカウント削除を申請できます。申請後30日間はデータが保持され（復元可能）、30日経過後にすべてのデータが完全に削除されます
  • 情報の修正：表示名・プロフィール写真・投稿したログとコメントはアプリ内から変更・削除できます

7. 位置情報について

位置情報は、ユーザーが明示的に許可した場合にのみ取得します。位置情報の取得を拒否した場合でも、地図上の任意の地点をタップして座標を指定すればログを投稿できます。

取得した位置情報はログの座標としてのみ使用し、ユーザーの行動追跡・広告配信には使用しません。バックグラウンドでの位置情報の取得も行いません。

8. 未成年者について

本アプリは13歳以上の方を対象としています。13歳未満の方の個人情報を意図的に収集することはありません。18歳未満の方が利用する場合は、保護者の同意を得たうえでご利用ください。

9. プライバシーポリシーの変更

本ポリシーを変更する場合は、このページの「最終更新日」を更新します。重要な変更がある場合はアプリ内でお知らせします。
